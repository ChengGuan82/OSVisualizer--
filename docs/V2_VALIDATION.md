# v2.0 验收记录

环境：Windows x64、Qt 6.9.0、MinGW GCC 13.1、CMake、Release 构建。v2 在原 v1 仓库上增量开发，原 exp 文件和 Release/v1.0 保持原样。

2026-09-13 最终结果：四个 CTest 目标全部通过；不启用 Qt 的独立核心构建三个测试目标全部通过。清除开发环境 PATH 后，Release/v2.0 在 offscreen 和原生 Windows 插件下均退出码 0。银行家与磁盘截图已逐张检查。

| 页面置换 | FIFO / LRU / CLOCK / OPT、快照、候选、环、对比 | 标准缺页数、单块、重复页、空输入拒绝、OPT 未来不再访问、随机独立 FIFO/LRU 参考实现 |
| 银行家 | Need、SAFE/UNSAFE、安全序列、每次检查、Work 释放 | 安全/非安全、单进程/单资源、Need=0、非法矩阵；200 组原实验对照 + 穷举参考结果 |
| 磁盘 | 四策略、方向、磁道边界、路径回放、对比 | 默认示例、左/右、同侧、重复/当前位置、空/单请求、非法输入；200 组守恒、对称性和原 SSTF 对照 |
| UI | 示例、自动刷新、前进/回退/播放/拖动 | gui_smoke 调用实际按钮和槽；银行家改变维度与错误输入；磁盘方向/空请求/错误输入；旧功能回归 |

## 重跑

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

四个 CTest 目标：`core_tests`、`banker_tests`、`disk_tests`、`gui_smoke`。每次完整构建会先运行这些测试，再部署到 Release/v2.0。

核心单独构建使用 `-DOSV_BUILD_GUI=OFF`，不查找 Qt。MinGW 测试程序会复制对应编译器的三个运行库，避免 PATH 中其他版本干扰。原银行家函数保留一个未使用参数警告，不影响结果，保留原文件便于直接对照。

默认银行家安全序列：P1 → P3 → P4 → P0 → P2。磁盘默认样例总移动量：FCFS 640、SSTF 236、SCAN 右向 331、C-SCAN 右向 382；左向分别为 SCAN 236、C-SCAN 386。
